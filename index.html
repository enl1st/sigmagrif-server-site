Состояние

Деплой (live)

  • Типовой поток: stop → upload → wake (или wake/upload/reload, если безопасно). Для некоторых сохранений (напр. Citizens/saves.yml) предпочтителен stop/upload/wake.
  • MCSH API: /files/contents принимает параметр path; /files/upload — multipart в directory.
  • Токен доступа хранится локально (напр. C:\Users\KOMPUKTER\Downloads\SigmaGrif_transfer\mcsh_token.txt, получен из браузерного _mcsh_at). В этот сайт токен намеренно не включён.

Точки и поведение (SigmaGrifSpawn v1.3)

  • Спавн лобби: -8.5, 72.0, 157.5 (yaw 0, pitch 0) в lobby (по актуальной конфигурации/сводке; платформа Y≈71).
  • Join: при входе телепорт в лобби.
  • Respawn: force-lobby-respawn: true — после смерти возрождение в лобби (на спавн лобби).
  • Платформа спавна: включена, материал WHITE_CONCRETE, size 5 (чтобы не падать в void).
  • Команды: /spawn (essentials.spawn), /setspawn (essentials.setspawn, op), /hub (sigmagrif.hub), служебная /sgspawn (sigmagrif.sgspawn, op). /survival упоминался в документации (perm sigmagrif.survival), наличие зависит от актуальной сборки.
config.yml (SigmaGrifSpawn, ключевые значения) 
default-world: lobby
main-world: world
spawns:
  lobby: { x: -8.5, y: 68.0, z: 157.5, yaw: 0.0, pitch: 0.0 }
force-lobby-respawn: true
spawn-platform: { enabled: true, material: WHITE_CONCRETE, size: 5 }
world-settings.lobby:
  permanent-day: true, time: 6000, disable-weather: true,
  disable-mob-spawning: true, disable-fire-tick: true,
  keep-spawn-loaded: true, difficulty: NORMAL, pvp: false

Примечание: в исторической заметке фигурировала высота ~68; фактическая точка спавна/платформа по сводке — около Y 71/72. Проверяйте актуальный спавн на live.

Экономика и торговля

SigmaGrifBuyer (/buyer)

  • GUI-скупщик шахтёрских ресурсов (Vault/Economy), звук/сообщения при продаже, откат при ошибке транзакции.
  • Действия: ЛКМ — 1 шт, ПКМ — 64 шт, Shift+ЛКМ — всё данного ресурса; кнопка «Продать всё» (hopper) — все доступные ресурсы.
  • Динамика цен: каждые ~30–60 мин выбираются 3–5 ресурсов с повышенным спросом (x1.5–x2.0). Штраф предложения: цена падает при массовой продаже (≈ -1% за стак проданного в цикле, минимум x0.5), сбрасывается на обновлении цикла. Таймер обновления отображается в меню.
  • Ресурсы и базовые цены (за 1 шт):

AuctionHouse и PrimeSeller

  • AuctionHouse Classic 2.2.4: defaultMaxListings: 5. Лимиты слотов по рангам выдаются permission auctionhouse.auctions.<N> (см. раздел рангов). Требуется проверка, что версия берёт лимит из permission.
  • Глобально (по конфигу): salesTax: 0.0, maxSalesTax: 100000, maxSellPrice: 100000. Per-group сниженная комиссия (Master) и повышенные/максимальные торговые лимиты (Legend+) в конфиге явно не выражены — зависят от возможностей плагина.
  • PrimeSeller: конфиги присутствуют (config/items/menu.yml), но явных per-group множителей продажи в конфиге не найдено. Отдельный множитель для SigmaElite требует поддержки версии плагина/проверки на live.
  • На сервере сосуществуют кастомный SigmaGrifBuyer и PrimeSeller; фактически используемый скупщик/интеграции — сверять на live.

Лимиты, кулдауны, бусты

Дома и кулдауны (Essentials, live/merged)

  • sethome-multiple: default 3, vip 5, staff 10; ранги — sigmamini 2, sigmalite 3, sigmacore 4, sigmaprime 5, sigmapro 6, sigmaelite 8, sigmaultra 10, sigmamaster 12, sigmalegend 15, sigmamythic 18, sigmaapex 25, sigma 50 (нужны essentials.sethome.multiple и essentials.sethome.multiple.<key>).
  • heal-cooldown: 1200с (20 мин, базово; у старших рангов bypass-пермишены).
  • command-cooldowns: repair: 10800 (3ч), feed: 600 (10 мин). command-cooldown-persistence: true.
  • Снижения КД реализованы частично через bypass-пермишены (Lite+ teleport, Elite/Legend back, Mythic+ heal/feed/repair и т.д.). Точная гранулярность «/repair hand 60м vs /repair all 3ч», «/back 15м после смерти (Prime)», тонкие КД /tpa,/home,/rtp вне лобби — не полностью покрывается одной глобальной шкалой Essentials и требует проверки/донастройки.

Jobs Reborn (бусты)

  • Бусты по деньгам выдаются через LuckPerms: jobs.boost.all.money.<X> (0.02 … 0.40).
  • generalConfig (ключевые): highest-permission-boost: true, add-permission-boost: false — чтобы при наследовании применялся наибольший буст ранга без суммирования. boost-persistence: true.
  • Соответствие: Mini +2%, Lite +5%, Core +7%, Prime +10%, Pro +12%, Elite +15%, Ultra +20%, Master +25%, Legend +30%, Mythic +35%, Apex/SIGMA +40%.

TAB (отображение)

Приваты блоками-рунами

  • Создание: ПКМ блоком-жетоном по земле — создаётся квадратная зона защиты вокруг точки. Блок расходуется (consume-block: true) и/или остаётся меткой (marker-block: true, сломать метку = снять приват).
  • Блок → сторона: QUARTZ 5x5, IRON 7x7, GOLD 9x9, DIAMOND 11x11, EMERALD 13x13, NETHERITE 15x15.
  • Лимиты: базово 3. Per-rank через sigmagrifclaims.limit.<N> / .unlimited (Pro 5, Elite 6, Ultra 8, Master 10, Legend 12, Mythic 15, Apex 30, SIGMA безлимит).
  • Защита: контейнеры/двери/животные защищены в чужих приватов, PvP в привате по умолчанию выключен (pvp-in-claims: false).
  • Команды: /claims (myclaims, claimlist), /unclaim (delclaim, abandonclaim), /trust <ник>, /untrust <ник>.

Контроль /fly (для рангов с essentials.fly: Mythic/Apex/SIGMA)

  • fly-control-enabled: true, fly-spawn-world: lobby.
  • Разрешён: в мире спавна lobby, в своих регионах (приват владельца или trusted), в защищённых зонах, где игроку разрешено строить.
  • Отключается: при перемещении в чужой приват/неразрешённую территорию; при PvP (урон между игроками, в т.ч. снаряды).
  • Применяется к игрокам с essentials.fly (не creative/spectator), без bypass/op. Bypass: essentials.fly.bypass / sigmagrifclaims.fly.bypass.
Caveat: «спавн» основного мира world вне защищённых зон/своих приватов автоматически не считается разрешённой зоной полёта — при необходимости выделить зоной. Полный контроль на чужих территориях вне системы приватов зависит от механизмов защиты (WG/др.).

RTP и перемещение

BetterRTP (v3.6.13) + перехват SigmaGrifSpawn

  • Важно: /rtp из lobby перехватывается SigmaGrifSpawn — выполняется собственный прямой случайный телепорт в world (радиус ~1000 от 0,0, посадка на поверхность). В этом сценарии кулдауны/логика BetterRTP могут не применяться.
  • Вне лобби (где команда обрабатывается BetterRTP) действуют настройки BetterRTP: default radius 10–1000, center 0,0, delay 5с (cancel on move), queue on, cooldown 600с по умолчанию, миры prison/creative отключены.
  • PermissionGroup cooldowns (world): sigmaprime/pro/elite/ultra — 300с; sigmamaster — 180с; sigmalegend — 60с; sigmamythic/sigmaapex/sigma — 30с.
  • Respect-флаги к WG/claim-плагинам в конфиге выключены (по текущему конфигу).

Расходники, руны и Контрабандист

Все предметы используют PersistentDataContainer (PDC) для идентификации, имеют кастомное имя/лор и скрытое зачарование (ItemFlag.HIDE_ENCHANTS). Кулдауны показываются в ActionBar при повторном клике.

Божья Аура (Свиток Очищения)

  • Материал: PAPER. Команда: /cleansescroll give <игрок> <кол-во> (perm cleansescroll.give).
  • ПКМ: частицы Particle.TOTEM, звук тотема/исцеления.
  • Снимает: POISON, WITHER, SLOW, SLOW_DIGGING, WEAKNESS, BLINDNESS, CONFUSION, HUNGER, LEVITATION.
  • Даёт ABSORPTION ур.0 (2 золотых сердца) на 15с. Расход 1 шт, КД 40с.
  • config: cooldown-seconds: 40, absorption-seconds: 15.

Явная пыль

  • Материал: GLOWSTONE_DUST. Команда: /reveal give <игрок> <кол-во> (perm revealdust.give).
  • ПКМ: волна END_ROD/VILLAGER_HAPPY + звук BLOCK_BELL_USE.
  • Невидимые игроки в радиусе 15 (кроме владельца) теряют INVISIBILITY и получают GLOWING на 10с.
  • В чат — сколько раскрыто (или «рядом никого»). Расход 1 шт, КД 25с.
  • config: radius: 15, glow-seconds: 10, cooldown-seconds: 25.

Дезориентация

  • Материал: BLAZE_POWDER. Команда: /disorient give <игрок> <кол-во> (perm disorient.give).
  • ПКМ: вспышка FLAME + SMOKE_LARGE, звук взрыва.
  • Враги в радиусе 7: CONFUSION + BLINDNESS на 4с, камера разворачивается на 180° (yaw +180, pitch сохраняется).
  • Расход 1 шт, КД 30с. config: radius, effect-seconds, cooldown-seconds.

Трапка (карманная клетка)

  • Материал: NETHER_STAR или OBSIDIAN (config item-material). Команда: /trap give <игрок> <кол-во> (perm trap.give).
  • ПКМ: полая коробка 5x5x4 (стены/пол/потолок) из обсидиана или чёрного стекла.
  • Заменяет только воздух/воду/траву/снег; твёрдые блоки, сундуки, спавнеры не трогает.
  • Блоки трапки нельзя сломать; авто-удаление через 15с. Блокируются телепорты эндер-перлом и плодом хоруса.
  • Расход 1 шт, КД 60с. При onDisable все активные трапки принудительно удаляются.
  • config: trap-material, cooldown-seconds: 60, duration-seconds: 15.

Ограничения, caveats и заметки

  • RTP из лобби: перехватывается SigmaGrifSpawn (кастомный телепорт в world), поэтому настройки/кулдауны BetterRTP в этом сценарии могут не действовать.
  • /fly: Mythic+ имеют essentials.fly; ограничение enforced SigmaGrifClaims v1.2 (lobby, свои/доверенные приваты, разрешённые protected-zones; авто-отключение в чужих зонах и PvP). Спавн основного мира world отдельно не размечен — нужна protected-zone/настройка при необходимости. Контроль на территориях вне приватов зависит от WG/других механизмов.
  • Лимиты приватов: глобальный базис 3 в конфиге, расширение по рангам реализовано в v1.2 через sigmagrifclaims.limit.* (LP-пермишены выданы).
  • Кулдауны (тонкая гранулярность): базовые значения заданы в Essentials; часть снижений — bypass-пермишены. Раздельные требования (repair hand 60м vs all 3ч, back 15м после смерти для Prime, точные per-rank /tpa,/home,/rtp) могут требовать доп. плагина/настройки.
  • AH/PrimeSeller: слоты AH — через auctionhouse.auctions.N (проверить поведение версии). Per-group комиссия/торговые лимиты AH и per-group множитель PrimeSeller (Elite) не подтверждены конфигом — зависят от возможностей плагинов.
  • Несоответствие данных меню: SigmaGrifMenu/config.yml содержит старый перечень донат-пакетов (VIP/Premium/Deluxe/Elite/Legend) — отличается от актуальной 12-ранговой линейки.
  • Citizens: NPC 0 — trait protected failed to load (pre-existing). Использовать citizens:npc; при правках saves — stop/upload/wake.
  • Секреты: MCSH bearer-токен (mcsh_token/_mcsh_at) не публикуется; обновлять при 401. Локальные пути артефактов приведены для администрирования.

Проверка после настройки (чек-лист)

  • LP: группы/веса 10–120, префиксы, наследование, lp user <nick> info.
  • Дома/киты: лимиты sethome и выдача/КД /kit ... (вкл. bonus/weekly), формат зелий.
  • Jobs: начисление соответствует бусту ранга (без суммирования).
  • AH: слоты по рангу; команды по доступу (hat/craft/ec/back/feed/ext/heal/repair/near/ptime/pweather/fly).
  • /fly: разрешён в lobby/своих регионах, отключается в чужих зонах и PvP (Mythic+).
  • Приваты: /claims показывает N/лимит; отказ сверх лимита.
  • RTP: из world — КД BetterRTP по группе; из lobby — перехват SigmaGrifSpawn.
  • TAB/Chatty: сортировка, префикс, отображение. Логи: нет ошибок YAML/загрузки.
