# SigmaGrif — данные сервера

Мини-сайт со сводкой по серверу **SigmaGrif** (Paper 1.16.5, MCSH).

Открыть сайт: https://enl1st.github.io/sigmagrif-server-site/

## Содержимое

- Обзор сервера и деплой (MCSH)
- Миры, лобби/спавн, SigmaGrifSpawn/Menu
- Плагины и системы
- Экономика: SigmaGrifBuyer, AuctionHouse, PrimeSeller
- 12 рангов: веса, префиксы, дома, слоты AH, Jobs-бусты, лимиты приватов
- Права/перки, киты EssentialsX
- Лимиты, кулдауны, TAB
- Приваты SigmaGrifClaims и контроль /fly
- RTP (BetterRTP + перехват из лобби)
- NPC, кейсы, автошахта, кастомный TNT
- Ограничения/caveats и чек-лист

> Токены/секреты в репозиторий не включены.
